# KUMARI Workflow

## Objetivo

Garantizar la construcción consistente de campañas, catálogos PDF y catálogos web para la marca KUMARI.

---

# FASE 1 - RECEPCIÓN

Cuando se reciban imágenes:

- No iniciar procesamiento inmediatamente.
- No generar prompts.
- No generar imágenes editoriales.
- No generar catálogos.

Esperar confirmación explícita del usuario indicando que el lote está completo.

Ejemplos válidos:

- "Ya terminé de subir todo"
- "Procesa el lote"
- "Puedes comenzar"

Hasta recibir dicha autorización únicamente registrar los archivos recibidos.

---

# FASE 2 - ANÁLISIS

Una vez autorizado:

1. Leer nombres de archivos.
2. Extraer código.
3. Extraer precio.
4. Identificar categoría.
5. Validar información disponible.

Formato esperado:

CODIGO_PRECIO.extensión

Ejemplo:

ACC-001_225.png

Resultado:

Código: ACC-001

Precio: Bs 225

---

# FASE 3 - CAMPAÑA EDITORIAL

Para cada producto:

1. Aplicar reglas de categoría.
2. Seleccionar escenario apropiado.
3. Mantener identidad visual KUMARI.
4. Preservar completamente el producto original.
5. Construir prompt final.

---

# FASE 4 - CONTROL DE CALIDAD

Verificar:

- Fidelidad al producto.
- Categoría correcta.
- Encuadre correcto.
- Escenario permitido.
- Sin texto.
- Sin logos.
- Sin marcas de agua.
- Calidad editorial premium.

---

# FASE 5 - CATÁLOGO

Incorporar productos validados al catálogo oficial.

Datos obligatorios:

- Imagen editorial
- Código
- Precio

---

# FASE 6 - PUBLICACIÓN

Generar:

- PDF
- Catálogo Web

Mantener identidad visual consistente en ambos formatos.
