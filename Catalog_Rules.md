# KUMARI Catalog Rules

## Convención de Archivos

Formato esperado:

CODIGO_PRECIO

Ejemplo:

ACC-001_225.png

Interpretación:

Código: ACC-001

Precio: Bs. 225

## Datos Obligatorios

Cada producto debe tener:

- Código
- Precio
- Fotografía original con retoque profesional de iluminacion, cambio de fondo
- Fotografía editorial

## Formato de Precio

Mostrar siempre:

Bs. 225

No utilizar:

225 Bs
225 BOB

## Orden de Visualización

1. Imagen
2. Código
3. Precio

## PDF

Diseño:

- Elegante
- Limpio
- Premium

Máximo:

9 productos por página

## Catálogo Web

Cada tarjeta debe mostrar:

- Imagen
- Código
- Precio

Debe ser:

- Responsive
- Mobile First
- Fácil de navegar

## Prohibiciones

No inventar:

- Precios
- Códigos
- Descripciones

Toda información debe provenir del nombre del archivo o datos proporcionados.
